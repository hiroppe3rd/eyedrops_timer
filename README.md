# 点眼タイマー

点眼する薬と各工程の時間をワークアウトとして登録し、音声ガイドに沿って実行するブラウザー向けタイマーです。完了したワークアウトは、利用者のGoogleアカウントを認証したうえでGoogleカレンダーに記録することを目指します。

## 主な機能

- ワークアウトの作成、編集、保存
- 点眼薬ごとの「準備」「直後の瞑想」「次の点眼までの待機」の設定
- ワークアウト一覧から選択してタイマーを開始
- 工程開始、残り5秒からのカウントダウン、工程完了の音声案内
- 完了画面からGoogleカレンダーへ実行内容を保存

最後の点眼薬には、次の点眼までの待機工程を設定しません。
