# 点眼タイマー 計画書

## 1. 目的

点眼薬と点眼前後の工程をルーティンとして登録し、音声ガイド付きタイマーで順番に実行できるブラウザー向けアプリを作る。完了したルーティンは、利用者のGoogleアカウントを認証してGoogleカレンダーに記録する。

## 2. 対象と前提

- 対象はブラウザーで利用するWebアプリとする。
- Googleカレンダーへの登録には、利用者本人のGoogleアカウント認証を使用する。
- Google Cloud 側の OAuth 同意画面を本番公開し、正規の Google カレンダー連携として運用する（必要な作業手順は [google_calendar_setup.md](google_calendar_setup.md) を参照）。
- ルーティン設定、音声設定、未保存の実行履歴は利用中のブラウザー内（`localStorage`）に保存する。サーバー同期や複数端末共有は初期対象に含めない。
- Google Cloud側でOAuthクライアントとGoogle Calendar APIを設定する手順は、実装・公開時に必要となる。

## 3. 機能要件

### 3.1 ルーティンの作成・編集・管理

- ルーティンに名前を付け、作成、編集、保存、削除ができる。
- ルーティンは、点眼する薬ごとの順序付きメニューで構成する。
- 点眼薬の順序はドラッグ＆ドロップで並び替えできる（一覧の並び替えも対象）。
- 各点眼薬について、薬名と次の工程を設定できる。
  - 準備
  - 直後の瞑想
  - 次の点眼までの待機
- 各工程には表示名と時間を設定できる。時間は表示名の右に配置した時間ボタンからダイアログを開き、テンプレートボタン選択（5秒、10秒、15秒、30秒、1分、1.5分、2分、3分、4分、5分、10分）または手入力（数値と「秒／分」単位の指定）で設定でき、0秒設定による工程の省略も許容する。
- 最後の点眼薬には待機工程を設けない。
- 不正な時間（負の値や秒換算で整数にならない値など）や、必須項目が未入力の設定は保存・実行できないようにする。

### 3.2 一覧と実行

- 保存済みルーティンを一覧表示する。
- 一覧からルーティンを選び、内容を確認して専用画面から開始できる。
- 工程を順番に進め、実行中の点眼薬名・工程名・残り時間・視覚的なプログレス表示を画面に表示する。
- 実際の点眼操作は「準備」の直後に行う流れとし、準備完了後に点眼して「直後の瞑想」へ進む。
- 実行中は「一時停止」「現在の工程をスキップ」ができる。
- 一時停止中の画面から「再開」「中断（最初からやり直し／一覧へ戻る）」を選択できる。中断時は完了画面やカレンダー保存へ進まない。
- バックグラウンド遷移やスロットリングの影響を受けないよう、残り時間は開始時刻と現在時刻の差分から算出する。
- タイマー実行中は Screen Wake Lock API 等を用いて画面スリープを抑止する（非対応ブラウザーではフォールバックする）。

### 3.3 音声ガイドとフィードバック

- ブラウザーの音声合成機能（Web Speech API）を使用する。
- 「開始」等のユーザー操作を起点に音声合成をアンロックし、以降の自動読み上げがモバイルブラウザー等でブロックされないようにする。
- 音声リストに `Google 日本語` が存在する場合は、デフォルト音声として自動選択する。利用者が音声を変更することも可能とする。
- 読み上げ速度は「普通（1.0x）」「やや早く（1.15x）」「早く（1.30x）」の3通りから選択できる。
- 最後に選んだ音声と読み上げ速度は `localStorage` に保存し、再度開いたときに復元する。
- 選択中の音声と速度で実際の読み上げイメージを確認できる「音声テスト」ボタンを配備する。
- 読み上げタイミングと内容：
  - **点眼薬の切り替わり・工程開始時**: 点眼薬名（薬の開始時）、工程名、設定時間、開始を読み上げる。
  - **準備完了時**: 薬名と点眼の実施をガイドする。
  - **工程終了前**: 残り5秒から「5、4、3、2、1」とカウントダウンを読み上げる。設定時間が5秒未満の短い工程の場合は、その設定秒数からカウントダウンを行う。
  - **カウントダウンの割り込み**: カウントダウン開始時に前の発話が再生中の場合は、再生中の発話をキャンセルして割り込む。
  - **工程終了時**: 工程名と完了を読み上げる。
- 音声合成が利用できない場合や消音時にもタイマー自体は動作し、画面上の視覚的フィードバック（プログレス表示・状態変化）および代替の簡易効果音（Web Audio API 等）で利用者に状態を知らせる。

### 3.4 完了とカレンダー保存

- 全工程の完了後、完了画面へ遷移する。
- 完了画面に実行したルーティン名、開始日時、完了日時を表示し、「保存」ボタンを設ける。
- 完了した実行結果は未保存の履歴としてブラウザー内に一時保存し、エラーやリロード後も後から保存を再試行できるようにする。
- 「保存」操作でGoogle認証を行い、ルーティン名と開始時間・終了時間をGoogleカレンダー（`primary` カレンダー固定）の予定として登録する。
- 保存処理中の連打防止や保存済みフラグ管理により、同じ実行結果が二重登録されないよう制御する。
- 認証や登録に失敗した場合はエラーを表示し、再試行できるようにする。

## 4. 実装フェーズ

1. **土台を整える**  
   ブラウザー向けの開発環境と画面構成を決め、アプリの起動方法を用意する。
2. **ルーティン設定を実装する**  
   スキーマバージョン付きのデータ構造、入力検証、作成・編集・削除・ドラッグ＆ドロップ並び替え、一覧表示を実装する。設定は `localStorage` に永続化する。
3. **タイマー画面を実装する**  
   現在時刻差分による工程の順次実行、残り時間・プログレス表示、一時停止・再開・中断（やり直し／一覧へ戻る）・スキップ、Screen Wake Lock によるスリープ抑止を実装する。
4. **音声案内を実装する**  
   ユーザー操作によるアンロック、`Google 日本語` の優先選択、音声・速度（1.0x / 1.15x / 1.30x）の `localStorage` 保存と復元、音声テストボタン、薬名・点眼ガイド・カウントダウン割り込み・5秒未満対応を実装し、非対応環境向けの視覚フィードバックと簡易効果音を追加する。
5. **完了画面とGoogleカレンダー連携を実装する**  
   未保存履歴の一時保存、Google Identity Services による認証（本番公開・正規OAuth連携）、`primary` カレンダーへの開始・終了時刻付き予定登録、二重登録防止を実装する。クライアントシークレットなどの秘密情報をブラウザーに含めない。
6. **一連の動作を検証する**  
   ルーティン作成から実行、一時停止・スキップ・中断、完了、カレンダー登録までを確認し、認証拒否・通信失敗・二重登録防止・再試行もテストする。

## 5. 主なデータ

- **永続化ルート（`localStorage`）**: スキーマバージョン（将来の拡張・マイグレーション用）、ルーティン一覧、音声設定（選択音声・再生速度）、未保存の実行結果履歴
- **ルーティン**: 識別子、名前、表示順、点眼薬と工程の順序、作成・更新日時
- **点眼薬**: 識別子、薬名、工程の一覧
- **工程**: 表示名、時間（0秒以上）、工程種別（準備／直後の瞑想／次の点眼までの待機）
- **実行結果**: 実行識別子、ルーティン名、開始日時、完了日時、カレンダー保存状態（未保存／保存中／保存済み）

### 採用技術スタック・構成方針

- **フロントエンド**: ビルドツールなしの静的構成（HTML5 / CSS3 / バニラ JavaScript ES Modules）
- **画面構成**: `public/index.html` 1ページ内でビューを切り替える SPA 構成（音声アンロック・Wake Lock・GISトークンをページ遷移で失わないため）
- **ディレクトリ構成**: `public/` をドキュメントルートとし、`public/js/`・`public/css/`・`public/assets/`・`public/manifest.webmanifest`（PWA対応）・OAuth 公開ページ（`privacy.html` / `terms.html`）を配置
- **実行環境**: Docker（Apache `httpd` ベース）で配信。開発時は `http://localhost:8080`、本稼働時はサブディレクトリ（`/eyedrops_calendar/`）配下での動作を前提とし、すべての参照パスを相対パス（`./`）で記述する
- **セキュアコンテキストに関する注意**: Google OAuth の「承認済み JavaScript 生成元」および Screen Wake Lock API は、開発用の `localhost` を除き **HTTPS（およびドメイン名）** を要求するため、本稼働環境では HTTPS 化・ドメイン設定を検討する

## 6. 受け入れ確認項目

- ルーティンと各工程を作成・編集・削除・並び替え・保存し、再読み込み後も確認できる。
- 工程順と設定時間に従ってバックグラウンドでもズレなくタイマーが進み、最後の点眼後に待機しない。
- 一時停止・再開・中断（やり直し／一覧へ戻る）・工程スキップが意図通りに動作する。
- 音声設定（選択した音声・3段階の速度）が `localStorage` に保存・復元され、音声テストボタンで試聴できる。また、薬名・開始・準備完了後の点眼ガイド・5秒前（または設定秒数）からの割り込みカウントダウン・完了の案内が行われる。音声不可時は視覚表示と簡易効果音で通知される。
- 全工程完了後に完了画面が表示され、保存操作でGoogleカレンダー（`primary`）にルーティン名と開始・終了日時が二重登録なく記録される。
- 認証拒否や登録エラー時も未保存履歴が保持され、利用者にエラーを明示したうえで再試行できる。
