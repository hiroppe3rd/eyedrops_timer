# 全画面レイアウト＆操作導線統一 修正計画（案3採用）

スマホで文字サイズを大きく表示した際のレイアウト崩れを解消するため、**案3（カード内シンプル化＋「⋯」メニュー集約）** を採用し、全5画面（SCR-01〜SCR-05）の操作導線を統一します。

## 1. 共通設計方針（全画面統一ルール）

点眼時（視界がぼやけた状態・大文字設定）でも迷わず・誤操作せず操作できるよう、全画面を以下の構造に統一します。

1. **ヘッダー（`.view-header`）の統一**
   - 従来の「戻る・タイトル・アクション（または空 `<span>`）」の3要素強制横並びを廃止します。
   - **上段に「← 戻る / 一覧へ」**（必要な画面のみ）、**その下にタイトル（`<h1>`・横幅100%）** を配置する縦積み／折り返し可能な構造にし、文字を大きくしてもタイトルが極端に狭くならないようにします。
2. **メイン操作（CTA）の統一**
   - 各画面で最も重要な操作（「＋ 新規作成」「保存」「タイマーを開始する」「一時停止／再開」「Googleカレンダーに記録」）は、**横幅100%のプライマリボタン（`.btn-block`）** に統一します。
   - 作成・編集画面（SCR-02）の「保存」ボタンもヘッダー右上から画面下部（または入力フォーム直下）の横幅100%ボタンへ移動し、SCR-03 / SCR-05 と同じ「上から順に確認・入力し、一番下の大きなボタンで決定する」導線に揃えます。
3. **補助・破壊的操作の集約（「⋯」メニュー）**
   - 「編集」「複製」「削除」などの補助操作・誤操作すると困る操作は、カード右上の **`⋯`（アクションメニュー）ボタン** に集約します。
   - メニューの表示方式は、文字を大きくしても画面外にはみ出さない **ボトムシート風アクションモーダル**（中央〜下部に大きめの縦並びボタンで表示）を採用します。
4. **大文字対応CSSの共通ルール**
   - `.meta-pill` の `white-space: nowrap` を廃止し、折り返し可能なメタ情報行へ変更します。
   - ボタンは `min-height: 44px` を確保し、横幅が足りない場合でも自然に表示されるようにします。
   - `.timer-clock` など大きな数値は `clamp()` を使い、狭幅・大文字時でも横スクロールが発生しないようにします。

## 2. 画面別の変更内容

### 共通ヘッダー（[index.html](../public/index.html) / [style.css](../public/css/style.css)）
- `.app-header-inner` に `flex-wrap: wrap` を設定し、「点眼タイマー」ロゴと「アプリ登録」ボタンが大文字時に窮屈にならないように調整します。

### SCR-01: ルーティン一覧（[routineListView.js](../public/js/views/routineListView.js)）
- **ヘッダー**: `<h1>ルーティン一覧</h1>` を全幅表示し、「＋ 新規作成」ボタンはヘッダー下（またはリスト上部）に横幅100%で配置します。
- **ルーティンカード**:
  - 上段: `☰`（並び替えハンドル）＋ ルーティン名（全幅）＋ 右端に `⋯` ボタン
  - 中段: `薬N種 ・ 計 MM分SS秒`（枠線なしの落ち着いたメタ情報行、または折り返し可能なピル）
  - 下段: `確認して開始`（横幅100%のプライマリボタン）
  - `⋯` メニュー内: 「編集」「削除」「キャンセル」
- **未保存完了履歴バナー（`.pending-banner` / `.pending-item`）**:
  - 項目タイトル・日時を全幅にし、「開く」ボタンを大きく配置、「削除」は補助ボタンまたは `⋯` メニューに逃がします。

### SCR-02: ルーティン作成・編集（[routineEditView.js](../public/js/views/routineEditView.js)）
- **ヘッダー**: 左上に `← 一覧へ`（戻る）＋ 必要に応じて右上に `⋯`（編集時のみ「このルーティンを削除」を格納）、その下に `<h1>ルーティン作成 / 編集</h1>`。
- **点眼薬カード（`.med-card`）**:
  - 上段: `☰` ＋ `薬 N` ＋ 右端に `⋯` ボタン
  - `⋯` メニュー内: 「この薬を複製」「この薬を削除（無効化制御あり）」「キャンセル」
- **工程入力行（`.step-input-row`）**:
  - 大文字時にラベル入力欄と時間ボタン（`.btn-duration`）が窮屈にならないよう、`flex-wrap: wrap`（狭幅時は縦積み）に対応します。
- **時間設定ダイアログ（`openDurationDialog`）**:
  - 従来のチップボタン群（`.template-grid`）を廃止し、**`<select>` ボックス形式** へ変更します（大文字時でも1行に収まり、OS標準ピッカーで選びやすいため）。
  - ラベル表記を「テンプレートから選択」から **「よく使う時間」** に変更します。
  - 連動仕様: 先頭に「手入力（カスタム）」選択肢を置き、現在の秒数が既定値に一致する場合は該当項目を選択状態にします。セレクト変更時は下の数値・単位欄へ即反映し、逆に手入力欄を編集した際はセレクトを「手入力（カスタム）」へ戻します。
- **点眼薬追加モーダル（`openMedicationPickerDialog`）と追加ボタン**:
  - 「テンプレート／既存から追加」などの「テンプレート」表記を **「よく使う薬」** に揃えます（例: ボタン「📋 よく使う薬／登録済みから追加」、ダイアログタイトル「よく使う薬／登録済みから追加」、タブ「よく使う薬」）。
- **下部CTA**: `＋ 点眼薬を追加` / `📋 よく使う薬／登録済みから追加` の下に、横幅100%の **`保存`** プライマリボタンを配置します。

### SCR-03: 開始前確認・音声設定（[confirmView.js](../public/js/views/confirmView.js)）
- **ヘッダー**: 上段 `← 一覧へ` ＋ 下段 `<h1>開始前確認</h1>`（空の `<span>` を削除し、他画面と統一）。
- **音声設定**: `.rate-btn-group` の速度ボタンが大文字時に均等折り返しできるよう調整します。
- **下部CTA**: 既存の横幅100% **`タイマーを開始する`** ボタンを維持します。

### SCR-04: タイマー実行（[timerView.js](../public/js/views/timerView.js)）
- **ヘッダー**: 3要素横並び（`薬 1 / 1`・`h1`・`Wake Lock`）を廃止します。
  - 上段: ルーティン名（`<h1>`・全幅）
  - 下段: `薬 1 / 1` と `Wake Lock 状態` を折り返し可能なステータス行として配置します。
- **操作エリア**:
  - 実行中: **`⏸ 一時停止`** を横幅100%の大きなボタンにし、`⏭ この工程をスキップ` はその下にセカンダリボタンとして分離配置します（誤スキップ防止）。
  - 一時停止中: **`▶ 再開`** を横幅100%のプライマリボタンにし、`↺ 最初からやり直す` と `一覧へ戻る（中断）` をその下に配置します。

### SCR-05: 完了・Googleカレンダー登録（[completeView.js](../public/js/views/completeView.js)）
- **ヘッダー**: 他画面と統一して、上段 `← 一覧へ` ＋ 下段 `<h1>ルーティン完了</h1>` に変更します（下部のカード外にも `一覧へ戻る` セカンダリボタンを置くと、下にスクロールした後も戻れます）。
- **下部CTA**: 既存の横幅100%の `Googleカレンダーに記録` ボタンを維持します。
