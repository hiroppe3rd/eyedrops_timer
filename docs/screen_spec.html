2. 共通仕様・技術制約

  • タイマー精度（背景スロットリング対策）: 残り時間は setInterval の減算に頼らず、工程開始時刻（再開時は残り時間を基準とした仮想開始時刻）と現在時刻（Date.now()）の差分から算出する。
  • 画面スリープ抑止: SCR-04 実行中は Screen Wake Lock API（navigator.wakeLock.request('screen')）を要求し、タブ復帰時にも再取得を試みる。非対応ブラウザーではエラーとせず通常動作を継続する。
  • 音声アンロック: モバイルブラウザー対策として、SCR-03 の「開始」ボタン押下（ユーザー操作）内で speechSynthesis を初回発話してアンロックする。
  • 音声不可・消音時のフォールバック: speechSynthesis 非対応または無音環境でもタイマーを止めず、視覚的な状態変化・プログレス表示に加え、Web Audio API による簡易ビープ音で通知する。

保存・保護・エラー処理仕様

機能・状態 仕様
未保存履歴の一時保存 SCR-04 完了時点で実行結果（開始日時・終了日時・保存状態=未保存）を localStorage に保存。リロード後も SCR-01 から再試行可能。
保存ボタン押下 Google Identity Services で認証後、primary カレンダーへ開始時間・終了時間付きの予定を登録。処理中はボタンを無効化し二重送信を防止。

エラー時の再試行 認証拒否・通信失敗時は具体的なエラーメッセージを表示し、一時保存データを維持したまま再試行ボタンを有効化する。
